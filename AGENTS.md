# Repository execution conventions

- Assume server commands are run from the repository root directory created by
  the default clone: `sample_complexity_of_feature_selection_in_deep_tabular_models`.
- Do not prepend commands with `cd sample_complexity_of_feature_selection_in_deep_tabular_models`;
  the shell is already in that directory.
- On the server, run Python through the repository virtual environment as
  `.venv/bin/python`, including training, tuning, scripts, and module commands.
