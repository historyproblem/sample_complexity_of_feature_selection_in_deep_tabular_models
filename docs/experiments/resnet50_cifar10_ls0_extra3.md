# Три дополнительных полных запуска

Команда последовательно выполняет три новых прогона по 60+90=150 эпох каждый,
всего 450 новых эпох обучения. Первый `full150/strict_ls0` остаётся отдельным
запуском; новый конфиг его не повторяет. Запускайте эту очередь после
завершения текущего полного прогона на той же GPU.

При прежнем dense-reference validation accuracy 0.9414 на эпохе 150:

| Порядок | Диапазон validation | soft_drop | hard_drop |
| ---: | --- | ---: | ---: |
| 1 | 0.924–0.9265 (92.40–92.65%) | 0.0149 | 0.0174 |
| 2 | 0.929–0.9315 (92.90–93.15%) | 0.0099 | 0.0124 |
| 3 | 0.935–0.9375 (93.50–93.75%) | 0.0039 | 0.0064 |

В каждом диапазоне разница равна 0.0025, то есть 0.25 процентного пункта.
Нижняя граница равна `reference150 - hard_drop`, верхняя —
`reference150 - soft_drop`. Это эквиваленты границ контроллера на последней
эпохе. Во время поиска adaptive lambda сравнивает качество с соответствующей
эпохой прежнего reference. Верхняя граница не запрещает получить более высокую
accuracy; фактический результат и выполнение нижнего ограничения измеряются.

Остальной рецепт совпадает с [первым полным запуском](resnet50_cifar10_ls0_full150.md):
`label_smoothing=0`, seed 42, adaptive lambda с auto-step, `min_keep_ratio=0.08`,
выбор кандидатов из эпох 31–60 с BN-калибровкой на 200 train-батчах каждого.
Восстановление наследует выбранные веса и длится 90 эпох с новым AdamW и cosine schedule.
Закреплены прежние хеши истории и начальных весов. Полные конфиги между
тремя моделями отличаются только soft/hard. Размер модели — результат обучения.

Выбор использует validation. После фиксации всех validation-строк runner
выполняет frozen official test на 10,000 примерах для каждой завершённой модели,
без обучения и обновлений BN на test. Сравнение с прежними результатами exploratory.
Кандидатная BN-калибровка добавляет 18,000 train forward batches для очереди.

## Проверка и запуск из корня репозитория

```bash
.venv/bin/python scripts/launch_resnet50_cifar10_ls0_extra3.py --validate-only
```

```bash
nohup .venv/bin/python -u scripts/launch_resnet50_cifar10_ls0_extra3.py \
  > resnet50_cifar10_ls0_extra3_v1.log 2>&1 &
tail -f resnet50_cifar10_ls0_extra3_v1.log
```

Результаты: `outputs/runs/resnet50_cifar10_ls0_extra3_v1/`.
`final_results.csv` содержит official test, фактическое число параметров,
validation accuracy, требуемое качество и `quality_feasible` для каждого прогона.
